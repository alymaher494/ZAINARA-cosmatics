# EmailJS Template Guide
# ============================
# في EmailJS Dashboard → Email Templates → Create New Template
# استخدم هذا المحتوى للقالب:

# Subject: طلب حجز جديد - {{from_name}}

# Content:
# ============================
# تم استلام طلب حجز جديد من موقع Zainara Cosmetics

# البيانات:
# الاسم: {{from_name}}
# الهاتف: {{from_phone}}
# الإيميل: {{from_email}}
# الخدمة المطلوبة: {{service}}
# التاريخ المفضل: {{date}}
# الوقت المفضل: {{time}}
# ملاحظات: {{message}}

# وقت الإرسال: {{submitted_at}}

# ---
# هذا الإيميل أُرسل تلقائياً من نموذج الحجز على الموقع.
# ============================

# المتغيرات المستخدمة في القالب (يجب مطابقتها في EmailJS):
# {{from_name}}     - اسم العميل
# {{from_phone}}    - رقم الهاتف
# {{from_email}}    - إيميل العميل
# {{service}}       - الخدمة المطلوبة
# {{date}}          - التاريخ المفضل
# {{time}}          - الوقت المفضل
# {{message}}       - رسالة العميل
# {{submitted_at}}  - وقت الإرسال
# {{to_email}}      - إيميل المستلم (محدد في الكود)
